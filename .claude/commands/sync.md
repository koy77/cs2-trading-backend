# /sync — проверка Steam-интеграции

Цель: $ARGUMENTS (профиль для синка; пусто — дефолтный профиль из конфига/фикстур).

## Шаги

1. **Фикстурный синк (дефолт).** `make steam-sync` (или `make steam-sync ID=7656119...`) — слепки
   реальных профилей, без сети; источник помечен как `fixture`. Так же ходят тесты (STEAM_PROVIDER=fixture).
2. **Live-синк.** `php artisan steam:sync --mode=real` (или режим `real` в панели/конфиге) — источник `live`;
   не гонять лишний раз: живые вызовы упираются в лимиты Steam.
3. **Повторный запуск.** Прогнать синк ещё раз: дублей нет — синк идемпотентен (upsert, а не insert).
4. **Лимиты и устойчивость.**
   - троттлинг / rate limiter перед вызовами Steam;
   - 429 и сетевые ошибки: ретраи с backoff, без «долбёжки» Steam и без падения джобы;
   - кэш инвентаря/цен: TTL, защита от stampede (повторный запрос — из кэша);
   - таймауты и понятные сообщения об ошибках.
5. **Тесты.** `make test` — SDK/фикстурные тесты зелёные; изменения клиента покрыты тестом.

Итог: короткий отчёт — что синкнул, какие коды/лимиты видел, что починил.
